# Interfaces funcionales en Java

Laboratorios de la guía técnica *Interfaces funcionales en Java* (Java 21 LTS), realizados para la clase de programación.

## Integrantes

- Juan Sebastián González
- Miguel Ángel Giraldo

## Contenido

| Carpeta | Laboratorio | Descripción |
|---|---|---|
| `lab1` | Generador de slugs | Convierte nombres de productos en slugs para URL, componiendo funciones con `andThen`. |
| `lab2` | Motor de validación | Interfaz funcional genérica `Regla<T>` con composición y fábricas. |
| `lab3` | Calculadora con estrategias | Reemplaza un `switch` por un mapa de `DoubleBinaryOperator`. |
| `lab4` | Motor de promociones | Reglas de negocio configurables usando solo interfaces funcionales. |

hecho por Juan Sebastian Gonzalez y Miguel Angel Giraldo.
